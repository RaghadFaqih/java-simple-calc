## ✨ Key Features

* ⚡ **Core Arithmetic:** Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
* 🛡️ **Robust Error Handling:** Prevents crashes gracefully with division-by-zero validation and input checking.
* 🔁 **Interactive Loop:** Perform multiple operations continuously without needing to restart the app.
* 🧼 **Clean Code Architecture:** Modular design utilizing isolated methods for each mathematical operation.

## 🛠️ Supported Operations

| Operation | Operator | Example Input | Output |
| :--- | :---: | :---: | :---: |
| **Addition** | `+` | `15 + 5` | `20.00` |
| **Subtraction** | `-` | `20 - 8` | `12.00` |
| **Multiplication** | `*` | `6 * 7` | `42.00` |
| **Division** | `/` | `50 / 2` | `25.00` |
